# Horizon Web

> **Historical frontend sandbox.** This repository is no longer actively developed and is not one of my showcase projects.

This repo was used to explore a web client for the Horizon / Jupiter Horizon AI system. Its current codebase is based heavily on Vercel's AI Chatbot template and should be read as frontend experimentation rather than as an original standalone application.

For the substantive systems work behind Horizon—multi-source ingestion, queues, vector retrieval, reranking, evaluation, monitoring, and service orchestration—see [`LiamVDB1/JupiterHorizon`](https://github.com/LiamVDB1/JupiterHorizon).

## Upstream foundation

The frontend is based on the open-source [Vercel AI Chatbot](https://github.com/vercel/ai-chatbot), built with Next.js and the Vercel AI SDK.

I keep this repository public for historical continuity, but the Jupiter Horizon repository is the canonical engineering case study.
